Reference pages are looked up, not read. Keep them exhaustive and keep
narrative out of them: anything a reader needs to understand before they can use
a symbol belongs in Guides.

Generated API pages land in this directory. A generator writes Markdown here at
build time, so the source of truth stays in the code's docstrings rather than in
this repository.

Delete this page once the first generated page exists, or keep it as the
directory's landing page and let the generator fill in around it.
