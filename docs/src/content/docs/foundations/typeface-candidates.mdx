Four candidates on identical specimens: the display line at the display size
and weight, a heading, a body paragraph at the reading measure, and a row of
the UI roles. The monospace stack is the system one in every block, because
mono is not part of the comparison.

Roboto is the shipped default, and it arrives with the package stylesheets, so
every consuming site gets it without wiring a font host. Inter and Geist are
loaded by this page alone. The system stack carries no web font at all.

The display line appears twice per candidate, at `-0.055em` and at `-0.02em`,
which is the value the type tokens carry. The tighter value crowds a face with
wider sidebearings, which is what the two columns are for. Heading weight stays
650 throughout.
