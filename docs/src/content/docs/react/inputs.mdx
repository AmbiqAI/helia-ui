Inputs should remain familiar, keyboard accessible, and visually quiet. Use
native controls where possible and add custom treatment only when it improves
clarity.

<InputShowcase client:only="react" />

## Initial set

- Primary, secondary, ghost, danger, disabled, icon-only, and icon-with-text buttons
- Text and search fields
- Select menus and a searchable combobox
- Radio groups and checkboxes
- Switches and sliders
- Segmented controls
- Later: file upload and date input when use cases require them
