## Dense data table

Tables are for comparison and dense structured data—not primary navigation.

<DataTable
  caption="Representative engine comparison"

  pageSize={3}

A table that becomes a tool rather than a comparison belongs on the React
side instead: the shadcn table primitives draw it, TanStack drives the sorting
and the paging, and the page pays for an island.

direct comparison and scatter plots for tradeoffs between two measures; keep the
