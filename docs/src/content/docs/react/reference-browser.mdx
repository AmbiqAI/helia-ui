title: Reference browser

---

import ReferenceBrowser from '@ambiqai/helia-ui/astro/ReferenceBrowser';
import Callout from '@ambiqai/helia-ui/astro/Callout';

export const rows = Array.from({ length: 32 }, (_, i) => ({
  id: `entry-${i}`,
  name: `Operation ${String(i + 1).padStart(2, '0')}`,
  kind: 'function',
  module: 'sample',
  group: i % 2 ? 'Arithmetic' : 'Conversion',
  href: '#reference-details',
  summary:
    i % 2
      ? 'Combines two input tensors. Check shape restrictions in the full reference.'
      : 'Converts the input representation. Consult the documented rounding behavior.',
  facets: { precision: [i % 3 ? 'FP32' : 'FP16'] },
}));
export const filters = [
  { id: 'group', label: 'Family', values: ['Arithmetic', 'Conversion'] },
  { id: 'precision', label: 'Precision', values: ['FP16', 'FP32'] },
];

The browser accepts rows and filter definitions from the product. It does not infer supported shapes or numerical behavior from a type label. Each entry links to its complete reference, and all rows remain available when JavaScript is disabled.

<Callout title="Consumer-owned meaning">
  Choose filter labels and values from your actual reference data. A matching
  entry does not imply that every combination of shape and precision is
  supported.
</Callout>

```text
ReferenceBrowser rows={rows} filters={filters} label="Find an operation"
```

<ReferenceBrowser
  rows={rows}
  filters={filters}
  label="Find an operation"
  nameLabel="Operation"
  itemsLabel="operations"
/>

## Reference details

The destination of each row is supplied by its consumer. Existing page and section anchors remain unchanged.
