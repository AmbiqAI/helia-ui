This page is for choosing. Every option the card parts and the motion system
offer is on it, side by side, each one showing the exact source that produces
it behind "Show code". Nothing here is a new component: the variants are
modifiers on `Card` and the transitions are classes in `recipes.css`.

The reference tables are on [Cards](/helia-ui/cards/) for the parts and in
`docs/design-system.md` for the motion tokens and the site theme.

## Tone

Four tones, each of them a different answer to "what stands in for the edge".
`outlined` is the default and `card` is its older name; `filled` and `muted`
are likewise the same tone. Padding and radius do not move between them, so a
row can mix tones and still line up.

## Media placement

`top` is the stacked card. `side` puts the frame down the leading edge at 40%
of the card and stacks again below 42rem, so a narrow viewport gets the top
placement whatever was asked for. `background` fills the card with the frame,
draws an overlay over it, and inverts the ink onto the fixed paper tone.

## StatCard

A figure, its label, and an optional change. The number is the child, so it can
carry a unit or markup; the delta is a `Badge` and its tone is the caller's,

card is the target and the cue is inside the same hit area.

## Reveal on scroll

`Reveal` fades and rises what it wraps the first time it reaches the viewport.
Use it on a section, not on every card in one: a page where each element
arrives separately reads as a page that is still loading. `stagger` is the one
exception, and it is still one wrapper.

The hidden state is a class the script adds, so the content is visible without
JavaScript, and the script returns before arming anything when the motion scale
is 0.

Replay re-arms every reveal on this page, so the entry can be watched without
scrolling away and back. It does nothing for a visitor who asked for reduced
motion, because nothing armed.
