## What the frontmatter does

`helia: { pageTitle: false }` is read by the `PageTitle` override the plugin
installs. The heading goes; a bare `_top` anchor stays in its place, which is
what the skip link at the top of the page and the overview entry in the table
of contents point at. The panel that held the title collapses, so the hero is
the first thing under the header rather than the second.

Every other page of this site is untouched: leave the field off and Starlight's
own heading renders exactly as it always did.

## What the page still owes

The hero headline is an `h1` by default, and it has to stay one here: the page
needs a heading, and suppressing the title removes the one Starlight gave it. A
section hero further down the same page takes `titleAs="h2"`.
