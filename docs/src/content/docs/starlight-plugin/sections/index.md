These pages exist to be navigated rather than read. They are the fixture for
the `sections` option: three sections, each with its own short sidebar, and a
landing page under `template: splash` so the option can be seen holding a
sidebar on a page Starlight would give none.

This page is the Demo home section, so the pane on the left carries that
section's name and its two pages. Open Demo guide or Demo reference and the
pane changes to that section alone. The site's own navigation, which every
other page on this site has, is back as soon as you leave the fixture.
