Four primitives carry the shapes that every other component builds on:
the card surface, the pill, the uppercase label, and the call to action. Each
one renders a class defined in `@ambiqai/helia-ui/recipes.css`, so an element that
cannot be produced by the component — a grid `<li>`, a Starlight shell
override, a scroll frame — reaches the same recipe by applying the class.

## Surface

One border, one radius, three backgrounds. Reach for `tone="muted"` when the
surface sits on the card background and has to recede, and `tone="paper"` for a
full-width band.

<div className="helia-card-grid helia-equal-grid not-content">
  <Surface>
    <strong>Card</strong>
    <p>The default raised surface for a discrete interface object.</p>
  </Surface>
  <Surface tone="muted">
    <strong>Muted</strong>
    <p>A recessed fill for a panel inside another surface.</p>
  </Surface>
  <Surface tone="paper">
    <strong>Paper</strong>
    <p>The quiet canvas used for page bands.</p>
  </Surface>
</div>

`padding` names a spacing step rather than a length, so a surface cannot drift
off the scale. `interactive` adds the shared hover background and the focus
ring; `href` renders an anchor.

<div className="helia-card-grid helia-equal-grid not-content">
  <Surface href="#surface" interactive padding="5">
    <strong>Interactive</strong>
    <p>Hover and focus this card to see the shared affordance.</p>
  </Surface>
  <Surface as="article" padding="2">
    <strong>Tight padding</strong>
    <p>Step 2 instead of the default step 4.</p>
  </Surface>
</div>

## Chip

`neutral` is the outlined default and reacts to pointer state when it links.
`accent` is the filled badge. `static` is read-only metadata and never
suggests it can be clicked.

<div className="helia-badge-row">
  <Chip>Neutral</Chip>
  <Chip tone="accent">Accent</Chip>
  <Chip tone="static">Static</Chip>
  <Chip href="#chip">Linked</Chip>
  <Chip size="md">Medium</Chip>
  <Chip size="md" tone="static">
    Medium static
  </Chip>
</div>

Horizontal padding sits one step above vertical at both sizes, which is what
makes the shape read as a pill rather than a rounded box.

## Eyebrow

The uppercase label above a heading. It renders a `<p>` by default; pass
`as="span"` inside a link or a flow that already owns the paragraph.

<Eyebrow>Section label</Eyebrow>

## Shared recipes

Two classes exist on their own because components apply them to elements the
primitives do not own.

- `.helia-focus-ring` is the site's single focus-visible treatment. Add
  `.helia-focus-ring--inset` when the control sits flush inside a clipping
  parent, where an outset ring would be cut off.
- `.helia-hover-surface` is the hover and focus affordance for a card: the
  background steps to the muted fill and the border lightens. It never
  transforms, because a card that moves under the pointer inside a grid
  reflows its neighbors.

## Icon

`Icon` is the one part here that backs no recipe. It resolves a name from Font
Awesome's free solid set at build time and writes the SVG into the page, so an
icon costs nothing at runtime and an unknown name fails the build instead of
rendering an empty box.

<p>
  <Icon name="gauge-high" /> gauge-high &nbsp;
  <Icon name="memory" /> memory &nbsp;
  <Icon name="circle-info" /> circle-info
</p>

```mdx
<Icon name="gauge-high" /> Latency
<Icon name="triangle-exclamation" label="Warning" />
```

It sizes and colors itself from the text it sits in, so it needs no rule at
the call site. Leave `label` off when the icon repeats the adjacent text, which
is most uses; supply it when the icon is alone in a cell or a heading and is
carrying the meaning by itself.
