Timelines show sequence without turning updates into a stack of cards. Use
grouped entries when several changes share a date or roadmap phase, and keep
descriptions concise enough to scan.

## Recent updates

Use chronological labels for changelogs, release histories, and editorial
update feeds. A group can contain one or several related entries.

<Timeline
  heading="What's new"
  actionLabel="View all updates"
  actionHref="#recent-updates"
  groups={[
    {
      label: 'July 20–24, 2026',
      datetime: '2026-07-20/2026-07-24',

clarify state, but the content and sequence should remain primary.

## Usage guidance

- Prefer a timeline when sequence or recency is part of the meaning.
- Group related changes under one date or phase rather than repeating labels.
- Keep the rail visually subordinate to titles and descriptions.
- Link only entries that have a meaningful destination.
- On small screens, place the date or phase above its entries.
