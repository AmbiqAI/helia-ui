Two parts: `BlockDiagram` is the canvas and `Block` is a node on it. A block
holds blocks, so the diagram nests as deep as the thing it describes without a
second component per level. Layout is CSS grid, the page ships no script, and
containment is the default relationship. Use `flow="sequence"` for a short
ordered process; its connectors turn downward when the stages stack on mobile.
Branches and loops belong in [Diagrams](/helia-ui/diagrams/).

## A flat row

Five peers on one line. `flow="row"` is the default, and a row stacks to one
column below 42rem, which is where five labels stop fitting on a phone.

## Nesting

A `Block` with children draws them in a set of its own. The children are more
`Block`s, so the whole diagram is one `<figure>` holding nested lists and a
screen reader walks the hierarchy the page draws. The ground steps at each
level, and the step is read off the markup rather than declared, so a subtree
moved a level in or out takes the ground of where it lands.

<BlockDiagram
  title="Pipeline with substeps"
  caption="Two levels. Each stage names what it is made of."
  flow="row"
>
  <Block label="Ingest" sublabel="Two sources">
    <Block label="Reader" emphasis="filled" />
    <Block label="Validator" emphasis="filled" />
  </Block>
  <Block label="Transform" sublabel="Pure functions">
    <Block label="Normalize" emphasis="filled" />
    <Block label="Resample" emphasis="filled" />
    <Block label="Window" emphasis="filled" />
  </Block>
  <Block label="Publish" sublabel="One writer">
    <Block label="Encoder" emphasis="filled" />
    <Block label="Store" emphasis="filled" />
  </Block>
</BlockDiagram>

## What belongs in a label

One to three words. The box was drawn to be taken in at a glance, and a block
carrying a sentence is a card that has lost its frame. A qualifier that will
not fit in the name goes in `sublabel`, on its own line and in the muted ink,
where it stays out of the way of the shape.

## Ordered stages

`flow="sequence"` uses an ordered list and connects only its top-level stages.
Keep labels short; nested blocks still describe what each stage contains.

<BlockDiagram flow="sequence" title="Build workflow" data-example="sequence">
  <Block label="Input" sublabel="Model and configuration" />
  <Block label="Compile" sublabel="Plan and generate" />
  <Block
    label="Output"
    sublabel="Integrate generated code"
    href="/helia-ui/getting-started/"
  />
</BlockDiagram>
